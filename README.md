# Linux Scripts & Config Experiments (for future me)

## Goal
Keep small Linux scripts and config experiments organized so I can quickly find, reuse, and safely improve them later.

## What’s inside
- Small automation scripts
- Dotfile/config snippets
- Notes on what I changed, why it works, and how to apply it

## Repo structure (template)
- `scripts/` — runnable scripts (with usage)
- `configs/` — config files/snippets
- `notes/` — decisions, troubleshooting, learnings
- `docs/` — setup/installation notes (if needed)

## How I should add new stuff
For every new project, create:
- a folder with a clear name
- a `README.md` inside with:
  - purpose
  - prerequisites
  - how to run / install
  - quick “gotchas”
  - what I’d improve next

## Maintenance rules
- Keep commands copy-pastable
- Add one-line description at the top of each script
- Never assume I’ll remember later—write it down
